# План расширения Нефтеюганск.инфо (по загруженному брифу)

## Инвентарь: что уже есть

- Каталог с 12 категориями и подкатегориями, районы, фильтры, поиск (обычный + AI).
- Реальные объявления в базе: создание с фото, статусы, модерация, продвижение (VIP/TOP/Срочно).
- Аккаунты: вход по email/Google, профили, роли в user_roles, админка с настоящей авторизацией.
- Админка: объявления, модерация, пользователи, бизнес, реклама, финансы, категории, районы, тарифы, логи, Growth-инструменты, AI-модерация и антифрод.
- Бизнес-профили (таблица business_profiles) — есть, но каталога компаний для посетителей нет.
- Монетизация: тарифы продвижения, страницы оплаты — без настоящего платёжного провайдера.

## Чего нет (по брифу)

- Каталог местных компаний и услуг для посетителей (бриф, раздел 4).
- Городской слой: новости, события, афиша (раздел 5).
- Кабинет продавца со статистикой (раздел 7) — частично есть «Мои объявления».
- Недавно просмотренные, настройки уведомлений (раздел 6).
- Мультигородская архитектура (раздел 12) — только подготовка.

## Предлагаемая первая партия (безопасная, проверяемая)

**P1 — Каталог компаний (раздел 4):**
1. Публичная страница «Компании» (/business): список проверенных бизнес-профилей из существующей таблицы, поиск по названию, фильтр по району и категории.
2. Страница компании (/business/:id): описание, контакты, часы работы, объявления этой компании.
3. Ссылка в навигации. Без выдуманных рейтингов и отзывов.

**P1 — Доделка кабинета продавца (раздел 7):**
4. «Мои объявления»: реальные просмотры и статус продвижения из базы (сейчас частично мок).

**P2 — Подготовка городского слоя (раздел 5):**
5. Таблицы для новостей/событий с модерацией + админ-раздел. Публичный показ только после появления реального контента — без выдуманных новостей.

## Что НЕ входит в эту партию

- Платёжный провайдер (нужны ключи и решение).
- Мультигородские домены (только архитектурная подготовка позже).
- Отзывы и рейтинги (требуют антиспам-системы).

## Ограничения

- Дизайн, анимации, карточки не трогаем.
- Изменения базы — только добавления (новые таблицы/колонки), без удаления.
- Каждый шаг проверяется в браузере.
